Moscas artificiais · sensores · predadores · ninhos e ovos

Código no GitHub Como instalar

O que é

Laboratório 2D onde moscas virtuais recebem estímulos (cheiro, distância, paredes, medo) e decidem sozinhas. Aranhas caçam e desistem. Ovos e ninhos fecham o ciclo.

Como rodar

  1. Baixe o ZIP do repositório
  2. Extraia a pasta FlyBrain
  3. Execute launch\\INSTALAR.bat
  4. Abra launch\\FlyBrain.bat
cd FlyBrain
set PYTHONPATH=src
python -m flybrain.main
